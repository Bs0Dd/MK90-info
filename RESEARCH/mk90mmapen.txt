-- Elektronika MK90 Memory Map (64KB) --

Zone 1: RAM (16KB)
[000000 - 037777]
Static RAM 8x2KB (KA537RU10B).


Zone 2: Secondary ROM (16KB)
[040000 - 077777]
1. Secondary mask ROM in MK90 2.0 (contains tests)
   (KA1835RE1-0009, only first 16KB used);
2. Memory window for MK92 2.0 ROM (BASIC extension or tests)
   (KA1835RE1-0010 as 2x16KB banks);
3. Address "mirror" if previous options disabled or not present.

*  An address "mirror" returns the address as the "read" value.
   For example, reading address 41022 will return the value 41022.
   This "mirror" occurs if some device (for example address decoder) has 
   transmitted a "reply" signal (OTV / BRPLY) to the processor, but no device
   has transmitted the value itself. In this case, the AD / BDAL bus lines
   retain a charge from setting the address, which the CMOS processor interprets
   as a value. A similar phenomenon is observed for devices that do not change
   the state of some lines, such as the KA1835VG5 (bits 0-7). In this case,
   the state of the unaffected lines will correspond to that when the address
   was set.

     
Zone 3: Primary ROM, part 1 (24KB)
[100000 - 157777]
Mask ROM with BASIC (KA1835RE1 -0001 or -0008).


Zone 4: System ROM (2KB)
[160000 - 163777]
1. Primary ROM if enabled in KA1835VG5 (used only in MK90 2.0);
2. Address "mirror" if previous option disabled.


Zone 5: Peripherals (1KB)
[164000 - 165777]
1. [164000 - 164007] - KA1835VG3 registers (write only);
2. [164010 - 164013] - МК92 2.0 TV controller registers (KA1835VG8, not released);
3. [164020 - 164027] - KA1835VG4 registers;
4. [164030 - 164037] - KA1835VG4 address decoder (CS101, CS110, CS111)~:
   A. [164030 - 164031] - Empty reply (no selection signal), "mirror";
   B. [164032 - 164035] - KA1835VG5 registers (CS101 for RG1 and CS110 for RG2);
   C. [164036 - 164037] - MK92 2.0 presence register, or address "mirror"
                          (CS111 is brought out to the expansion connector);
5. [164060 - 164067] - KA1835VG4 registers in MK92 1.0 (connection with KA1835D51);
6. [164070 - 164077] - KA1835VG4 address decoder in MK92 1.0, "mirror"~;
7. [164200 - 164203] - KA1835VG6 registers in MK92 2.0 (plotter / tape);
8. [165000 - 165377] - KA1835VG4 address decoder (CSEA)~:
   A. [165000 - 165177] - KA512VI1 registers / SRAM (64 addresses in total);
   B. [165200 - 165377] - KA512VI1 duplication (the first 64 addr. are repeated);
9. Causes BUS ERROR (TRAP 4) if trying to:
   - Read KA1835VG3 registers;
   - Read MK92 registers when it's not connected;
   - Read any other unused address.

~  The KA1835VG4, in addition to the serial input/output registers (the first 4), 
   also contains an address decoder for external devices with 4 (remaining)
   addresses and a range of 165000-165377 (0xEA**). When accessing these addresses,
   the controller generates a "reply" signal (OTV / BRPLY) and sends the corresponding
   CS101, CS110, CS111, or CSEA selection signal to the external device.
   The KA1835VG4, integrated into the MK92 1.0, does not have any devices on its decoder.
   

Zone 6: Primary ROM, part 2 (4.5KB)
[166000 - 176777]
Same chip as Zone 2.


Zone 7: Peripherals 2 (0.5KB)
[177000 - 177777]
1. [177514 - 177517] - Unreleased character printer registers (BASIC 1.0);
2. [177546 - 177547] - UART (current loop) timer register in MK92 2.0 (KA588VA4);
3. [177560 - 177567] - UART (current loop) registers in MK92 2.0 (KA588VA4);
4. Causes BUS ERROR (TRAP 4) otherwise.
